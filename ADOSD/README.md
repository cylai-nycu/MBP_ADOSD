\# Quantum LDPC Code Decoder



This repository implements BP / MBP / AMBP decoding with OSD / ADOSD

for various quantum LDPC codes.



\## Quick Start

1\. Edit `ldpc\_parm.h` to select a code.

2\. Compile the project.

3\. Run the decoder.

\- How to run simulations: `docs/run.md`

\- Code construction and matrix format: `docs/matrix\_format.md`

\- Decoder and parameter configuration: `docs/parameters.md`
