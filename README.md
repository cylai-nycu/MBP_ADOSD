## DS-CSS dedicated decoder

The Windows DS-CSS executable reuses the MBP4 and ADOSD core from `ADOSD/ldpcQaun` and lives in `DS_CSS/`. See [`DS_CSS/README.md`](DS_CSS/README.md) for the build and command-line instructions. The supported inputs are `[[18,6,3]]` (original and DS-distance-3 generators) and `[[36,12,5]]`.
